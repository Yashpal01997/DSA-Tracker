# DSA Tracker

Bosscoder DSA Problem Tracker — 272 problems (Phase 0 Basics + Full Cheat Sheet).

- ✅ Checkbox + notes (Pattern, Approach, Complexity, Extra) per problem
- ☁️ Auto-saves to Google Drive on every change
- 📱 PWA — install on phone, tablet, PC, Mac via Chrome
- 🔗 Direct LeetCode / GFG links for every problem
